Stevemod 弓弩流派设计文档

杀戮尖塔 2 · Stevemod · Steve 角色弓/弩流派

版本：最终整合版

1. 设计概述

把 Minecraft 的弓、弩、箭机制移植进杀戮尖塔 2，三条硬规则：

  • 弓与弩是发射媒介，本身不造成伤害；伤害全部来自被发射的箭。
  • 箭袋是独立于抽牌堆/弃牌堆的第三牌堆，无上限、跨战斗继承、战斗内免费排序。
  • 箭袋为空时，弓与弩均不可打出。

MC 的“蓄力越久伤害越高”落地为箭袋越厚、箭种越精、单回合发射越多，箭伤害越高。弩的“先装填后击发”落地为：弩牌只装填，生成 0 费保留派生牌，再打出才发射。

2. 核心机制

2.1 箭袋牌堆

  • 独立第三牌堆，无数量上限。
  • 跨战斗完整继承：未取用的箭带入下一场、下一层、下一章，存于 RunState。
  • 战斗内免费无限拖拽排序；地图/商店只读。
  • HUD 常驻显示总数、NEXT ▸ 下一发箭种、各箭种数量徽章。

2.2 弓：发射

  • 打出弓牌 → 袋顶取箭 → 立即结算 → 箭进消耗堆。
  • 无派生牌、无「装填」关键词。空袋不可打出。

2.3 弩：装填 → 发射

  • 打出弩牌 → 袋顶取箭 → 不结算伤害 → 生成 0 费、保留派生牌 → 原弩进弃牌堆。
  • 派生牌卡名 = 装填 + 箭种名 + 的 + 弩名。
  • 打出派生牌 → 发射所装填的箭 → 箭进消耗堆。
  • 派生牌保留，本回合不打就留到下回合，占手牌位。
  • 箭数不足时弩不可打出。战斗结束未打出的派生牌销毁，其箭进消耗堆。

2.4 伤害公式

单支箭伤害 = 箭种基础 + 卡牌修正 + 满弦 + 力量附魔 + 力量遗物
最终伤害 = 单支箭伤害 × 1.5(易伤) × 1.25^发光层数 × 其他
  • 加算项先求和，再进乘算。
  • 易伤 ×1.5，多层只叠持续。
  • 发光每层 ×1.25，累乘（2 层 ×1.5625，3 层 ×1.953125）。

2.5 空袋规则

牌型袋空时
弓牌不可打出
弩牌不可打出
发射至多 N 支至少需 1 支
发射 N 支需 ≥ N 支

2.6 消耗堆与回收

箭用后进消耗堆（战斗内，不跨战斗），在消耗堆查看器中以“已消耗弹药”分区按箭种计数。回收牌可从消耗堆取回箭。

2.7 迟缓：延后敌人意图

迟缓 X：目标接下来 X 次行动跳过，意图保留并顺延。

  • 1 层 = 少打一次，意图顺延一回合。
  • 2 层 = 跳过两次，意图队列后移两回合。
  • UI 在敌人头顶显示“迟缓 X”与顺延后的意图。

2.8 再生：MC 数值体系

再生 X（N 回合）：每回合结束回 X 点，持续 N 回合，不递减。总恢复 = X×N。适用于 Stevemod 全流派，与原版再生分开结算。

10. 平衡与实现要点

10.1 空袋禁射的压力

弹药供给是硬需求。初始遗物每回合 +1 只够 1 费弓；补弹网络 = 补充箭矢、制箭、回收箭、重制箭矢、拾荒者、箭袋回收。齐射与连发弩是消耗大户，打出前确认袋深。

10.2 累乘锚点

易伤 ×1.5 + 3 层发光 ×1.953125 = ×2.93。光灵箭是唯一稳定发光来源，每支 1 层、持续 2 回合。过强时优先削减发光持续时间或光灵箭供给，不改回加算。

10.3 迟缓的 Boss 价值

1 层 = 少打一次；瞄准射击+迟缓之箭 = 2 层 = 跳过两次。迟缓之箭供给应比伤害之箭更稀缺。

10.4 再生全局统一

固定量 × 固定回合、不递减，独立 buff ID（如 SteveRegen），与原版再生分开结算。

10.5 穿透相邻判定

取目标左右各一名存活敌人，各结算等量伤害（含箭种、附魔、乘算）。相邻单位也触发箭种效果——穿透光灵箭可一次给 3 目标挂发光。

10.6 首射之弓边界

  • 袋空仍不可打出。
  • 齐射射 3 支，仅第 1 支免消耗并 +4（+3+1），其余正常取箭、只吃 +1。
  • 复制箭进消耗堆，可被回收。
  • 与「无限」叠加仍只免 1 支。
  • 弩线零收益。

10.7 实现要点

  • 箭数据：ArrowData { type, uid }；箭袋存 RunState，消耗堆箭单独列表。
  • 派生牌：CardRarity.Special，带 Retain 与 cost=0，卡名与 DynamicVars 装填时写入。
  • 附魔：卡牌字段 EnchantmentType（或 List 支持双槽）。
  • canUse 统一检查箭袋箭数。
  • HUD 订阅箭袋与消耗堆变更实时刷新。
  • 迟缓：敌人挂 DelayPower，回合开始层数 > 0 则跳过意图、层数 -1。
  • 跨战斗写回：OnCombatEnd 一次性写回。

一句话总结：弓只有「发射」——打出即射、即时结算、无派生牌；弩才有「装填」——打出先取箭锁定、生成 0 费保留的“装填[箭种]的弩”、再打出才发射。箭袋无上限、跨战斗继承、免费排序、消耗堆可回收；箭是唯一伤害源，空袋禁射；发光与易伤累乘，迟缓延后敌人意图，再生按 MC 数值不递减；Boss 遗物「首射之弓」强化每回合第一张弓的第一支箭。
