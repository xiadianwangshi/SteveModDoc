Stevemod 弓弩流派
设计文档 · 最终版

杀戮尖塔 2 · Stevemod · Steve 角色 · 弓 / 弩双线独立流派

箭袋持久化 空袋禁射 弓·发射 弩·装填 附魔驱动 累乘增伤

1设计概述

把 Minecraft 的弓、弩、箭机制移植进杀戮尖塔 2。核心是三条硬规则：

  • 弓与弩是发射媒介，本身不造成伤害；一切伤害与效果来自被发射的箭。
  • 箭袋是独立于抽牌堆 / 弃牌堆的第三牌堆，无上限、跨战斗继承、战斗内免费拖拽排序。
  • 箭袋为空时，弓与弩均不可打出。

MC 的“蓄力越久、箭速越高、伤害越高”落地为：箭袋越厚、箭种越精、单回合发射越多，箭的伤害越高。弩的“先装填后击发”落地为：弩牌打出时只装填，生成 0 费保留的派生牌，下回合或当回合再发射。

双线独立：弓与弩是两种独立流派，同一局只会出现其中一条。两线共享箭袋规则、箭种表、附魔表与伤害公式，但起始遗物、起始牌组、专属卡池与 Boss 遗物各自独立；功能相似的辅助牌合并为通用池，两线都可出现。

2核心机制

2.1 箭袋牌堆

  • 独立第三牌堆，无数量上限。
  • 跨战斗完整继承：战斗结束未取用的箭原样带入下一场战斗、下一层、下一章，数据存于 RunState。
  • 战斗内可免费、无限次拖拽排序，零成本；地图 / 商店等非战斗场景只读。
  • HUD 常驻显示：总数、NEXT ▸ 下一发箭种、各箭种数量徽章；展开面板含消耗堆箭统计。

2.2 弓：发射

  • 打出弓牌 → 从袋顶取箭 → 立即结算伤害与箭种效果 → 箭进入消耗堆。
  • 弓牌无派生牌、无「装填」关键词。
  • 空袋不可打出（UI 置灰）。

2.3 弩：装填 → 发射

  • 打出弩牌 → 从袋顶取箭 → 不结算伤害 → 生成一张 0 费、保留的派生牌置入手牌 → 原弩牌进弃牌堆。
  • 派生牌卡名 = 「装填」+ 所装填箭种名 + 「的」+ 弩名。
  • 打出派生牌 → 发射所装填的箭，结算伤害与箭种效果 → 箭进入消耗堆。
  • 派生牌带「保留」：本回合没打出就留到下回合，占一个手牌位。
  • 装填时若箭袋箭数不足装填需求，弩牌不可打出。战斗结束时仍未打出的派生牌销毁，其锁定的箭进入消耗堆。

2.4 伤害公式

单支箭伤害 = 箭种基础伤害 + 卡牌修正 + 满弦层数 + 力量附魔 + 力量遗物
最终伤害   = 单支箭伤害 × 1.5（易伤）× 1.25^发光层数 × 其他乘数
  • 所有加算项先求和，再统一进入乘算。
  • 易伤：×1.5，多层只叠持续时间。
  • 发光：每层 ×1.25，多层累乘（2 层 ×1.5625，3 层 ×1.953125）。
  • 易伤与发光相乘，不进加算。

2.5 空袋规则

牌型袋空时
弓牌不可打出
弩牌不可打出（无法装填）
“发射至多 N 支”类至少需 1 支箭
“发射 N 支”类需 ≥ N 支箭

2.6 消耗堆与回收

箭被发射 / 取用后进入消耗堆（战斗内概念，不跨战斗），在消耗堆查看器中以“已消耗弹药”分区按箭种计数，不混入卡牌网格。回收类卡牌与遗物可从消耗堆取回箭放入箭袋。

2.7 迟缓：延后敌人意图

迟缓 X：目标在接下来 X 次行动中跳过行动，其意图保留并顺延到迟缓结束后执行。

  • 例：敌人意图“攻击 12”，被施加 1 层迟缓 → 本回合不攻击，意图保留；下回合执行“攻击 12”，同时生成新意图。
  • 2 层迟缓 = 跳过 2 次行动，意图队列整体后移 2 回合。
  • UI 在敌人头顶显示“迟缓 X”与顺延后的意图预览。

2.8 再生：MC 数值体系

再生 X（持续 N 回合）：每回合结束恢复 X 点生命，持续 N 回合，不递减。总恢复量 = X × N，固定可预期。适用于 Stevemod 全流派，与原版再生分开结算，不混用、不叠加。

5池划分与通用牌

5.1 划分原则

池内容规则
通用池补弹、过牌、回收、附魔、防御、箭种转化、双线能力两局都出现；文本可同时提到弓与弩，但不含「装填」动词（引用派生牌名除外）
弓专属池发射类攻击牌、满弦体系、首射强化只进弓局
弩专属池装填类攻击牌、派生牌体系、节弹与装填放大只进弩局

「装填」仍是弩专属关键词：通用牌里只出现“装填…的弩”作为派生牌名称引用，不把“装填”当动词用。

10平衡与实现要点

10.1 空袋禁射的压力

弓弩都不能空放，弹药供给是硬性需求。起始遗物每回合 +1 支只够 1 费弓的节奏；补弹网络 = 补充箭矢、制箭、拾箭、回收箭、重制箭矢、拾荒者、箭袋回收。齐射（至多 5 支）和 连发弩（2 支）是消耗大户，打出前必须确认袋深。

10.2 累乘的数值锚点

易伤 ×1.5 + 3 层发光 ×1.953125 = ×2.93，接近三倍。光灵箭是唯一稳定发光来源，每支只给 1 层、持续 2 回合。若实测过强，优先削减发光持续时间或光灵箭供给量，不改回加算。

10.3 迟缓的 Boss 战价值

1 层迟缓 = 敌人少打一次；瞄准射击 + 迟缓之箭 = 2 层迟缓 = 跳过 2 次行动。对 Boss 大招是接近“回合跳过”的硬控，因此迟缓之箭的供给应比伤害之箭更稀缺，先古箭袋随机池需单独配平权重。

10.4 再生全局统一

再生采用“固定量 × 固定回合、不递减”，独立 buff ID（如 SteveRegen），与原版再生分开结算，所有 Stevemod 流派统一引用。

10.5 穿透的相邻判定

以目标为锚点取左右各一名存活敌人，各结算一次等量伤害（含箭种、附魔、发光 / 易伤乘算）。相邻单位也触发箭种效果——穿透光灵箭可一次给 3 个目标挂发光。

10.6 首射之弓的边界

  • 袋空仍不可打出：免消耗不解决空袋，第一张弓仍需袋非空。
  • 多箭牌只保第一支：齐射 射 3 支，仅第 1 支免消耗并 +4（+3+1），第 2、3 支正常取箭、只吃弓牌 +1。
  • 复制箭进消耗堆：可被 回收箭 / 重制箭矢 取回。
  • 与「无限」遗物叠加：两者都限次数，最坏情况首射同时触发，仍只免 1 支。
  • 弩线零收益：强化只作用于弓，弩线强度仍由附魔与装填节奏决定。

10.7 实现要点

  • 箭数据：轻量 ArrowData { type, uid }；箭袋存 RunState，消耗堆的箭单独列表。
  • 派生牌：CardRarity.Special，带 Retain 与 cost=0，卡名与 DynamicVars 在装填时按箭种动态写入。
  • 附魔：卡牌自定义字段 EnchantmentType（或 List 支持双槽），装填 / 发射时读取并写入派生牌。
  • canUse 统一检查箭袋箭数；弓牌袋空置灰，弩牌箭数不足置灰。
  • 箭袋 UI 订阅箭袋与消耗堆变更实时刷新 NEXT 与数量徽章；拖拽走 moveArrow(from, to) 接口，免费无限次。
  • 意图延后：敌人挂 DelayPower，OnEnemyTurnStart 层数 > 0 则跳过本次意图执行、意图对象保留、层数 -1；迟缓先于意图重 roll 结算。
  • 跨战斗写回：OnCombatEnd 一次性写回箭袋，按遗物回收消耗堆箭，销毁未打出的派生牌（其箭进消耗堆）。
  • 卡池过滤：弓局注册“通用池 13 + 弓专属 14”，弩局注册“通用池 13 + 弩专属 11”；Boss 遗物池分离。

一句话总结：弓只有「发射」——打出即射、即时结算、无派生牌；弩才有「装填」——打出先取箭锁定、生成 0 费保留的“装填[箭种]的弩”、再打出才发射。箭袋无上限、跨战斗继承、免费排序、消耗堆可回收；箭是唯一伤害源，空袋禁射；发光与易伤累乘，迟缓延后敌人意图，再生按 MC 数值不递减。功能相似的 13 张辅助牌合并为通用池，弓局与弩局各注册“通用池 + 本线专属池”，两线起始牌组只差攻击牌。
